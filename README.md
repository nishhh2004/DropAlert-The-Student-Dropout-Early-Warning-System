## 📌 Problem Statement

Student dropout is a major challenge in educational institutions.  
Many students at risk are not identified early, leading to:

- 📉 Academic failure  
- 🎓 Increased dropout rates  
- ❌ Lack of timely intervention  

**DropAlert** solves this by predicting whether a student is:

- ✅ Safe  
- ⚠️ At Risk  
- 🚨 Critical  

using Machine Learning.

---

## 🚀 Solution

DropAlert is an **AI-powered web application** that allows counsellors or educators to:

- Input student details  
- Instantly get dropout risk prediction  
- Take early action to prevent dropouts  

The system uses a trained **classification model** to analyze student performance and behavioral patterns.
